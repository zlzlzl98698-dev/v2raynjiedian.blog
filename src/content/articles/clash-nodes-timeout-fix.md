## 30 秒急救口诀 (Answer-First)

遇到 Clash 节点全红超时，**按顺序执行以下四步，99% 的问题均能立即解决**：
1. **第一步（最常见）：同步系统时间** ➜ Windows 右下角时钟右键 ➜「调整日期/时间」➜ 点击 **「立即同步」**；
2. **第二步：更新订阅** ➜ 在订阅列表上右键 ➜ 点击 **「Update (更新订阅)」**，排除套餐到期或节点迁移；
3. **第三步：更换测试地址** ➜ 将测速 URL 从默认的 Google 改为 `https://cp.cloudflare.com/generate_204`；
4. **第四步：重启内核** ➜ 在设置中点击 **「重启核心 (Restart Core)」**，清理端口死锁。

## 一、导致节点全红超时的五大元凶深度剖析

### 元凶一：系统时间与互联网时间不同步 (占比 70%)
现代代理协议（VLESS、Trojan、Shadowsocks-2022）为了防止重放攻击（Replay Attack），底层均内置了严格的时间戳防伪机制。
- **机制原理**：客户端发出的握手请求时间戳，与海外服务器的时间差**绝不能超过 60 秒**；
- **现象**：电脑因休眠、主板电池老化或双系统切换导致本地时钟哪怕慢了 2 分钟，服务端就会立即单方面丢弃数据包，导致所有节点在软件中检测全部超时。

### 元凶二：默认 7890 端口被占用或被杀毒软件阻断
Clash 默认使用 `7890` 端口作为混合代理端口（Mixed Port）。
- 如果你之前使用过其他 VPN、v2rayN 或电脑上安装了某些带有网络加速功能的下载软件，可能会霸占 7890 端口；
- 此时 Clash 无法绑定监听端口，整个代理链路彻底瘫痪。

### 元凶三：机场订阅已到期或主域名遭遇阻断
很多用户忘了自己购买的机场套餐流量已经耗尽或已到期。此时服务器认证网关会自动拒绝连接，客户端同样会表现为全红超时。

## 二、图文解决步骤：手把手逐一排除

### 第一步：精确同步电脑时间
1. 在 Windows 任务栏右下角右击时间，选择 **「调整日期和时间」**；
2. 确保开启了「自动设置时间」；
3. 点击下方的 **「立即同步」** 按钮，直到下方出现绿色的“成功同步时间”对勾；
4. 返回 Clash Verge，再次点击测速，通常节点会瞬间恢复绿色延迟。

```text
[右击时钟] ──▶ [调整日期和时间] ──▶ [点击立即同步] ──▶ [回到 Clash 测速恢复正常]
```

### 第二步：修改代理端口解决冲突
1. 打开 Clash Verge Rev 的 **「设置 (Settings)」**；
2. 找到 **「混合端口 (Mixed Port)」**，默认值为 `7890`；
3. 将其手动修改为一个冷门端口号，例如 `17890` 或 `27890`；
4. 点击保存，系统代理会自动重定向至新端口。

### 第三步：修复 Windows 关机残留的系统代理死锁
很多用户在关机前没有正常退出 Clash，导致 Windows 系统的底层代理设置卡死在 `127.0.0.1:7890`，出现“关掉软件所有网页都打不开，打开软件又超时”的死锁怪圈：
1. 按键盘 `Win + I` 打开系统设置 ➜ 进入「网络和 Internet」➜「代理」；
2. 找到「手动设置代理」，将 **「使用代理服务器」** 开关手动拨为 **关闭**；
3. 随后以管理员身份运行 Clash Verge，重新开启软件的系统代理。

## 三、高级排查：TUN 模式驱动异常修复

如果开启了 TUN 模式后出现整个电脑无法上网：
1. 打开设备管理器 ➜ 查看「网络适配器」；
2. 检查是否存在名为 `Meta-TUN` 或 `Wintun` 的网卡设备，且上面是否有黄色感叹号；
3. 若存在报错，在 Clash Verge 设置中关闭 TUN 模式 ➜ 点击「卸载 TUN 服务」➜ 重新以管理员权限打开软件安装一次网卡驱动即可。
